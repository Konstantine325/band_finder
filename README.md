# Band Finder

Band Finder is a university web development project created for the HY-359 Web Programming course
at the Computer Science Department of the University of Crete. 
The application was developed using Node.js, Express, JavaScript, HTML, CSS, Bootstrap, and MySQL. 
It allows users and bands to create accounts, manage profiles, publish events, and submit or moderate reviews,
demonstrating full-stack development, database integration, session-based authentication, and responsive web design.
